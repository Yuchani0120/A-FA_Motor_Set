이번에 대학생자작자동차대회에서 EMRAX 계열 모터 + PM100DX Controller를 활용해서 모터 맵과 파라미터 추천 값을 추출하는 프로그램입니다.
Matlab FOC 예제와 모터 제어 이론들을 참고해서 기본 세팅을 완료하였고, 이전부터 사용했던 EMRAX208MV + PM100DX 조합으로 얻은 CAN 주행 데이터로 회귀를 진행해서 보다 더 정밀한 결과를 얻고자 하였습니다.
PM100DX의 세팅이 워낙 간단하다보니, I_q,d 전류, Break_Speed, 기어비 및 타이어 직경, DC 방전 전류 제한 값을 설정하여 빠른 모터맵 확인과 안전하면서 최적화된 파라미터를 얻도록 제작하였습니다.
또한, 수동적으로 값을 입력해보면서 모터맵도 생성하도록 제작해봤습니다
의미가 있을까 싶지만, 나중에 Optimal Lap 데이터를 넣으면 그거에 맞게 값을 추천해주는 기능도 넣어보고 싶은데 한번 도전해보겠습니다.
